🗓 Google Calendar

Connect your Google Calendar using a read-only Google OAuth connection.

Your Google Client ID is not a password. Do not enter a Google Client Secret here.

Google Cloud configuration

  1. Create/open a project in Google Cloud.
  2. Enable Google Calendar API.
  3. Configure OAuth consent screen.
  4. Create an OAuth Client ID for Web application.
  5. Add your GitHub Pages origin under Authorized JavaScript origins.
  6. Enter the Client ID above.
  7. Press Connect.

Required Calendar permission:
calendar.readonly
